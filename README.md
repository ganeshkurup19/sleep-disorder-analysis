# Sleep Disorder Analysis

## 📊 Project Overview

This project analyzes sleep patterns, lifestyle factors, demographic information, and sleep disorders using data cleaning, Excel, and Power BI.

The objective of this project is to explore the relationships between sleep duration, sleep quality, stress levels, physical activity, BMI, heart rate, blood pressure, age, and sleep disorders.

## 🛠️ Tools & Technologies

- Power BI
- Excel
- Data Cleaning
- Data Analysis
- Data Visualization
